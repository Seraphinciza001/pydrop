Écran et caméra sur l'ordinateur

Affichez ce téléphone sur un PC et pilotez-le à la souris, ou montrez sa caméra avant ou arrière.

Ordinateur
Afficher
Android 12 ou plus. La caméra s'affiche en grand sur le PC. Pour s'en servir de webcam (Zoom, Teams, Meet) : OBS Studio sur le PC → capture de la fenêtre → « Démarrer la caméra virtuelle ».
Première fois — avec un câble USB (conseillé)
  1. Ouvrez les Options pour les développeurs et activez Débogage USB.
    Absentes ? Paramètres → À propos du téléphone → touchez 7 fois Numéro de build.
  2. Branchez le téléphone au PC et acceptez Autoriser le débogage USB (cochez « Toujours »).
  3. Touchez Afficher sur l'ordinateur ci-dessus.
  4. Vous pouvez ensuite débrancher : l'affichage continue sans fil, même en partage de connexion, jusqu'au redémarrage du téléphone.
Ou sans câble — téléphone sur un Wi-Fi
  1. Activez Débogage sans fil et ouvrez-le.
    Impossible quand le téléphone partage sa connexion (point d'accès) : Android le désactive aussitôt.
  2. Touchez Afficher sur l'ordinateur, puis Associer l'appareil avec un code d'association et tapez le code à 6 chiffres sur le PC.
N'autorisez que vos propres ordinateurs.

Nom de ce téléphone

C'est le nom que verront les ordinateurs.

Afficher ce téléphone sur l'ordinateur
Une seule fois : autorisez l'ordinateur grâce au débogage sans fil d'Android 11 ou plus.
  1. Ouvrez les Options pour les développeurs.
    Absentes ? Paramètres → À propos du téléphone → touchez 7 fois Numéro de build.
  2. Activez Débogage sans fil, puis touchez la ligne pour l'ouvrir.
  3. Touchez Associer l'appareil avec un code d'association.
  4. Tapez le code à 6 chiffres sur l'ordinateur, dans PyDrop.

Notifications sur le PC

Vos messages WhatsApp, SMS, appels manqués… s'affichent sur vos ordinateurs connectés. Android doit d'abord autoriser PyDrop à lire les notifications.

  1. Touchez Autoriser l'accès, puis activez PyDrop.
  2. Android affiche « Paramètre restreint » ? Touchez Infos sur l'appli ci-dessous → menu ⋮ en haut à droite → Autoriser les paramètres restreints, puis refaites l'étape 1.
  3. Revenez dans PyDrop : c'est activé.
